# Aplicación base - Software V

Proyecto sencillo para practicar el manejo de cambios mediante una herramienta Git GUI.

## Funciones

- Ventana principal adaptable.
- Etiqueta y campo de texto.
- Saludos amigables y formales.
- Botones para mostrar el mensaje y limpiar el formulario.
- Validación cuando el nombre está vacío.
- Paleta azul noche, marfil y coral con estados de foco visibles.

## Ejecución

Abre `index.html` en un navegador web.

## Comprobación

```bash
node --test test.js
```
